Privacy Policy for My Cycle Keeper

Last Updated: July 30, 2026

Your privacy is paramount. My Cycle Keeper is built to run entirely client-side. It operates with a strict zero-knowledge architecture regarding your personal data.

1. No Data Collection or Transmission

  • Completely Offline: We do not maintain any external application web servers, user database buckets, or analytics platforms.
  • Zero Logs: Your personal health metrics, calendar inputs, cycle information, tracking history, and custom notes are handled exclusively on your own machine.
  • No Third-Party SDKs: The application includes no external advertising software, analytics packages, trackers, or telemetry scripts.

2. Local Device Storage & Encryption

  • All structured logs are saved strictly to your device's browser sandbox environment using an IndexedDB database engine.
  • If you enable a secure 4-digit login lock, all data stored inside your local instance is fully compiled using cryptographic AES-256-GCM encryption. This happens entirely on your hardware via the native Web Crypto API standard.

3. Google Drive Backup Integration

The app offers an optional Google Drive Backup functionality to safeguard your information against unexpected local device resets:

  • Isolated Permissions: By connecting your account, the app requests access strictly via the isolated https://www.googleapis.com/auth/drive.appdata scope.
  • Sandboxed Access: This permission allows our local script to save a data backup container directly to a hidden directory in your personal cloud. My Cycle Keeper cannot view, read, modify, or interact with any other contents or files in your Google Drive account.
  • Encrypted Storage: The backup file payload remains entirely encrypted by your local device PIN configuration before it leaves your machine. We have no servers, keys, or technical means to read your encrypted database files.
  • Google API Services User Data Policy Compliance: My Cycle Keeper's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. User Control & Data Retention

Because your tracking metrics never leave your possession, you retain full control over your data.

  • You can clear your local database at any time by selecting the "Erase All Data" option within the app settings menu or by resetting your local web browser cache data.
  • Disconnecting the app via your personal Google Account security preferences instantly terminates API authorization tokens and queues your sandboxed backup folder for automatic server removal.

5. Contact Information

If you have any questions regarding this offline architecture or code implementations, you can audit the source repository directly or open an informational ticket via our primary deployment repository at https://github.com/fishese/period-tracker.
